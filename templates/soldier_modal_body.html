Project Overview

Unmanned Aerial Vehicles (UAVs) have become an essential technology for modern surveillance and defense operations. Monitoring large-scale environments such as forests, mountains, and border regions is difficult using conventional methods. Detecting camouflaged soldiers remains particularly challenging because they blend naturally with surrounding terrain and environmental conditions.

This project introduces a robust multi-stage deep learning framework for detecting camouflaged soldiers from UAV imagery. The system utilizes RT-DETR, a real-time object detection architecture, to identify potential human targets from aerial images. To improve localization accuracy and reduce false detections, the Segment Anything Model (SAM) performs precise pixel-level segmentation of detected objects.

The framework further converts detected locations into real-world geographic coordinates through geospatial mapping techniques. These coordinates are displayed within an interactive monitoring dashboard, enabling defense personnel to monitor target locations, improve situational awareness, and support mission-critical decision-making.

Core Framework Features

{{ ic.icon('heli', 'icon text-primary me-2') }}UAV-Based Surveillance System

Designed for processing live aerial video feeds and image frames captured by drone cameras.

{{ ic.icon('radar', 'icon text-primary me-2') }}Real-Time Human Detection

High-speed targeting of individuals using state-of-the-art RT-DETR (Real-Time DEtection TRansformer).

{{ ic.icon('shield', 'icon text-primary me-2') }}Camouflaged Identification

Specialized training datasets optimized to detect patterns blending in environments (woodlands, desert, snow).

{{ ic.icon('crop', 'icon text-primary me-2') }}SAM Pixel-Level Segmentation

Integrates Meta's Segment Anything Model (SAM) for extreme boundary outlining, reducing false-positive boxes.

{{ ic.icon('crosshair', 'icon text-primary me-2') }}Geospatial Coordinate Mapping

Translates pixel bounding boxes into GPS coordinates using camera angle, altitude, and mapping models.

{{ ic.icon('chart-line', 'icon text-primary me-2') }}Interactive Monitoring Dashboard

A live map display tracking drone location and targeted detections with telemetry feeds.

{{ ic.icon('gauge', 'icon text-primary me-2') }}Real-Time Analytics
